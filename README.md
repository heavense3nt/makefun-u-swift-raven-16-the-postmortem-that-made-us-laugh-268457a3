One short account, two sentences, of the silliest and most fatal time an AI coding
agent misunderstood what it was asked: a one-query column rename that became a
47-migration rewrite, a dropped production column at 2 a.m., and a 4,000-line
pull request titled "cleanup" waiting for review.

`main.ts` writes the story to `/output/entry.txt` via `MAKEFUN_OUTPUT_DIR`,
guarded to the gate: 1–400 characters, one or two sentences.
